# baocaoquy - Yan 2026 Tooling & Project Dashboard

Báo cáo phân tích tiến độ khuôn và dự án Yan 2026 (Sheet SUM) với hiệu ứng 3D trực quan và đối soát chéo chuẩn xác 100%.

## 🌐 Trực tiếp trên GitHub Pages
Sau khi kích hoạt GitHub Pages trong mục Settings -> Pages (Source: Deploy from a branch -> `main` / `root`), bạn có thể truy cập website tại:
`https://hiennh163-art.github.io/baocaoquy/`

## 📁 Cấu trúc thư mục
- `index.html`: Giao diện Dashboard chuẩn Cyber-Executive Dark Mode
- `style.css`: Hệ thống thiết kế Glassmorphism & hiệu ứng trực quan
- `app.js`: Động cơ xử lý số liệu 5 nghiệp vụ & hạt phân tử 3D Three.js
